# 🍉 Air Slice — Hand-Tracked Fruit Slicing Game

A browser-based, Fruit-Ninja-style slicing game controlled entirely by your bare hand. No touchscreen, no controller — just swipe through the air in front of your webcam to slice flying fruit. Built as a **single HTML file**, combining computer vision with real-time canvas game rendering.

## ✨ Features

* ✋ Real-time hand-tracked slicing — your hand *is* the blade
* 🍎 Fruit launches upward under real projectile physics (gravity-based arcs)
* 💥 Fruit splits into two halves along the exact angle of your swipe, with a juice-splash particle burst
* 🔥 Combo bonus for slicing multiple fruits in a single swipe
* 💣 Bombs mixed in — slice one and the game ends instantly
* ❤️ Three lives — missing a fruit (letting it fall) costs one
* 🏆 High score saved locally (persists between sessions)
* 🔊 Interactive sound effects (slice, bomb, miss, combo)
* 🌐 Runs entirely in the browser, no backend
* 📄 Single-file implementation

## 🛠️ Technologies Used

* HTML5
* JavaScript
* MediaPipe Hands
* Canvas API (2D game rendering + physics)
* Web Audio API
* localStorage (high score)

## ▶️ How to Play

1. Open the website.
2. Allow camera access when prompted.
3. Swipe your hand through the air wherever fruit appears — a fast enough motion slices anything it crosses.
4. Avoid bombs 💣 completely — slicing one ends the game immediately.
5. Don't let fruit fall past the bottom of the screen — three misses ends the round.
6. Try to slice several fruits in one continuous swipe for a combo score bonus.
7. Tap the restart button (top right) any time to start over, or use "Play Again" on the game-over screen.

## 💡 Project Goal

This project demonstrates real-time, physics-driven gameplay controlled entirely by AI-based hand tracking — no hardware beyond a standard webcam and a browser.
